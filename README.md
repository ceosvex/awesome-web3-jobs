# Awesome Web3 Jobs [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of the best resources, job boards, companies, and tools for finding (and getting hired for) web3 and crypto jobs in 2026 — developers, designers, product, community, legal, and everything in between.

Crypto hiring is exploding: [Electric Capital](https://www.developerreport.com/) tracks tens of thousands of monthly active developers, regulatory clarity (MiCA, UAE, Singapore, Hong Kong) is bringing traditional companies on-chain, and stablecoin + RWA + L2 + zk teams are all competing for the same talent. This list helps you find the roles, the companies, and the prep resources you need to land one.

**Legend** — 💰 commercial intent · 🆓 free resource · 🏛 established · 🚀 growing fast

General-purpose web3 and crypto job boards with listings across engineering, product, design, growth, and operations.

- [CryptoJobsList](https://cryptojobslist.com) — One of the oldest crypto job boards, covers global remote roles. 🏛

## Learning Paths by Role

- **Smart Contract Engineer** → [Become a Blockchain Developer](https://web3vacancy.com/become-a-blockchain-developer) → [CryptoZombies](https://cryptozombies.io) → [Solidity by Example](https://solidity-by-example.org) → [Ethernaut](https://ethernaut.openzeppelin.com)
- **Security Auditor** → [Smart Contract Auditor Career](https://web3vacancy.com/smart-contract-auditor-career) → [Secureum Bootcamp](https://www.secureum.xyz) → [Damn Vulnerable DeFi](https://www.damnvulnerabledefi.xyz) → Code4rena / Sherlock contests
- **Rust / L1 Engineer** → [Solidity vs Rust](https://web3vacancy.com/solidity-vs-rust) → [Rust Book](https://doc.rust-lang.org/book/) → [Solana Cookbook](https://solanacookbook.com) → [Near Protocol Docs](https://docs.near.org)
- **Community Manager** → [Crypto Community Manager Guide](https://web3vacancy.com/crypto-community-manager-guide) → Run a real Discord / Telegram / Farcaster channel for 3+ months
- **Product Manager** → Use 10+ protocols as a real user → Write public teardown threads → [Web3 Careers Guide](https://web3vacancy.com/web3-careers)
- **Non-Technical Entry** → [Non-Technical Web3 Jobs](https://web3vacancy.com/non-technical-web3-jobs) → Start in community or BD → Transition lateral after 12 months

## Contribute

Contributions are welcome. Please read the [contribution guidelines](CONTRIBUTING.md) first.

1. Fork this repo.
2. Add your resource in the correct section, alphabetically within the section, with a one-line description.
3. Make sure the link is live, the resource is actively maintained, and it genuinely helps job-seekers.
4. Submit a pull request with a short explanation of why the addition belongs.

**Rejected submissions:** dead links, paid services disguised as free, "ICO jobs" scams, projects no longer active, affiliate-spam.
